Pakai Setiap Download Excel

Cara Pakai

  1. Tampilkan Bookmark Bar Belum tampil? Tekan Ctrl + Shift + B.
  2. Drag Tombol ini ke Bookmark Bar ❇️Fix Download SI TOLE PeDe
  3. Buka halaman laporan SI TOLE PeDePilih Tahun/Tahap dan klik tombol "Lihat".
  4. Klik bookmark Fix DownloadTunggu pesan "Fix aktif".
    (*ulangi tahapan ini sebelum kilik tombol download)
  5. Klik tombol DownloadFile Excel langsung terunduh.

Jangan diklik di sini. Klik nanti di halaman SI TOLE PeDe.

Aman dipakai. Alat ini hanya memperbaiki tombol Download di SI TOLE PeDe. Prosesnya di browser kamu saja, tidak ada data yang dikirim keluar dan data di server tidak berubah.

Tidak bisa diseret?
  1. Klik kanan tombol hijau, pilih Copy link address.
  2. Klik kanan Bookmark Bar, pilih Add page.
  3. Tempel di kolom URL, beri nama Fix Download, lalu simpan.
